# Добавление нового объекта на шкалу

## 1. Подготовить PNG

Положи изображение объекта в папку:

```text
public/img/textures/items/NNN.png
```

где `NNN` — новый ID объекта в формате `001`, `248`, `329`.

Рекомендации к PNG:

- прозрачный фон
- без лишних пустых полей, если возможно
- нормальное качество без сильных артефактов
- имя файла должно точно совпадать с ID

Пример:

```text
public/img/textures/items/329.png
```

---

## 2. Добавить запись в `public/data/items.json`

Теперь вся информация по объекту хранится в одном месте: внутри `frames`.

Нужно добавить новый блок в `frames` по ключу нового ID.

Пример:

```json
"329": {
  "layout": {
    "x": 0,
    "y": 0,
    "width": 250,
    "height": 250
  },
  "size": {
    "exponent": -7,
    "coeff": 1,
    "realRatio": 1
  },
  "visualLocation": {
    "titleX": 220,
    "titleY": 470,
    "titleScale": 1,
    "titleWrap": true,
    "descriptionX": 660,
    "descriptionY": 240,
    "zoomOffset": 0.1
  }
}
```

---

## 3. Что означают поля в `layout`

```json
"layout": {
  "x": 0,
  "y": 0,
  "width": 250,
  "height": 250
}
```

Смысл:

- `x`, `y` — положение центра PNG относительно центра объекта
- `width`, `height` — логический размер картинки
- эти же значения используются для области клика

### Важный принцип

Если у объекта:

```ts
sprite.anchor.set(0.5, 0.5);
sprite.position.set(layout.x, layout.y);
```

то:

- `layout.x/y` двигают картинку внутри контейнера объекта
- `layout.width/height` определяют её прямоугольник

Если PNG уже нормально подготовлен и не требует сдвига, часто можно начать с:

```json
"layout": {
  "x": 0,
  "y": 0,
  "width": 250,
  "height": 250
}
```

---

## 4. Что означают поля в `size`

```json
"size": {
  "exponent": -7,
  "coeff": 1,
  "realRatio": 1
}
```

Смысл:

- `exponent` и `coeff` задают размер в метрах как `coeff × 10^exponent`
- `realRatio` — поправка к реальному соотношению размеров

Примеры:

- `1 × 10^-7` = 100 нм
- `1.1 × 10^-7` = 110 нм

Обычно для новых объектов удобно взять `size` от похожего по масштабу объекта и поправить только `coeff` и `exponent`.

---

## 5. Что означают поля в `visualLocation`

```json
"visualLocation": {
  "titleX": 220,
  "titleY": 470,
  "titleScale": 1,
  "titleWrap": true,
  "descriptionX": 660,
  "descriptionY": 240,
  "zoomOffset": 0.1
}
```

Смысл:

- `titleX`, `titleY` — позиция заголовка
- `titleScale` — масштаб текста заголовка
- `titleWrap` — перенос строки у заголовка
- `descriptionX`, `descriptionY` — позиция карточки описания
- `zoomOffset` — насколько близко камера подлетает при клике

Удобный способ настройки:

- взять похожий объект
- скопировать его `visualLocation`
- подвинуть вручную после проверки в приложении

---

## 6. Как подобрать `layout`

Если новый объект должен вести себя как соседний объект похожего масштаба:

- возьми у него `layout`
- замени `width/height` под свой PNG
- при необходимости подстрой `x/y`

### Простой стартовый вариант

Если PNG уже обрезан по контуру и расположен удобно:

```json
"layout": {
  "x": 0,
  "y": 0,
  "width": 250,
  "height": 250
}
```

### Если картинку нужно сместить

Например, если объект должен визуально стоять чуть левее или выше:

```json
"layout": {
  "x": -40,
  "y": -20,
  "width": 250,
  "height": 250
}
```

---

## 7. Добавить переводы

Во всех locale-файлах нужно добавить ключ нового ID:

```json
"329": {
  "title": "Название",
  "description": "Описание объекта."
}
```

Минимум — добавить в основной язык, но лучше сразу во все поддерживаемые языки.

ID должен совпадать с ключом в `frames`.

---

## 8. Проверить соответствие ID

Один и тот же ID должен совпадать везде:

- имя PNG-файла
- ключ в `items.json -> frames`
- ключ в locale-файлах

Например, если объект `329`, то везде должен быть именно `329` / `329.png`.

---

## 9. Если объект не появился

Проверь по порядку:

- существует ли файл `public/img/textures/items/329.png`
- есть ли ключ `"329"` в `public/data/items.json`
- есть ли внутри него `layout`
- есть ли внутри него `size`
- есть ли внутри него `visualLocation`
- добавлен ли перевод `"329"`

---

## 10. Если картинка смещена

Править нужно `layout`:

```json
"layout": {
  "x": 0,
  "y": 0,
  "width": 250,
  "height": 250
}
```

Что за что отвечает:

- `x` — сдвиг картинки по горизонтали
- `y` — сдвиг картинки по вертикали
- `width` — ширина кликабельной области и логический размер картинки
- `height` — высота кликабельной области и логический размер картинки

Если новый объект должен вести себя почти так же, как соседний, удобнее всего скопировать у него `layout` и поправить только размеры и смещение.

---

## 11. Если область клика неправильная

Область клика строится из `layout.width/height`.

Проверь:

- соответствует ли `width` реальной ширине объекта
- соответствует ли `height` реальной высоте объекта
- не слишком ли большие пустые поля у PNG
- не нужен ли дополнительный сдвиг `x/y`

---

## 12. Если заголовок или описание стоят не там

Править нужно:

Для заголовка:

```json
"titleX"
"titleY"
"titleScale"
"titleWrap"
```

Для карточки описания:

```json
"descriptionX"
"descriptionY"
```

Если описание слишком большое или визуально неудачно расположено, проще всего взять координаты у похожего объекта и потом вручную подкрутить.

---

## 13. Если зум при клике слишком слабый или слишком сильный

Правь:

```json
"zoomOffset"
```

Обычно это небольшое число, например:

```json
0
0.05
0.1
```

Чем больше значение, тем ближе камера подлетает к объекту.

---

## Быстрый практический рецепт

Для нового объекта обычно удобнее всего так:

1. Найти похожий по масштабу объект
2. Скопировать его запись из `items.json`
3. Поменять:
   - ID
   - PNG
   - `coeff` / `exponent`

4. Подкрутить:
   - `layout.x/y`
   - `layout.width/height`
   - `titleX/Y`
   - `descriptionX/Y`
   - `zoomOffset`

5. Добавить переводы

---

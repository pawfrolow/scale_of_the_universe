# Добавление нового объекта на шкалу

## 1. Подготовить PNG

Положи картинку в:

```text
public/img/textures/items/NNN.png
```

где `NNN` — новый ID в формате `001`, `248`, `328`.

Лучше использовать:

* отдельный PNG на прозрачном фоне,
* без лишних пустых полей, если возможно,
* с нормальным качеством.

---

## 2. Добавить ID в список текстур

В `src/helpers/getTextureIds.ts` увеличь максимум:

```ts
const MAX_COMMON_TEXTURES = 328
```

Если добавляешь объект `329`, ставь `329`.

---

## 3. Добавить размер объекта

В `public/data/sizes.json` добавь запись:

```json
{
  "objectID": 329,
  "exponent": -7,
  "coeff": 1,
  "cullFac": 1,
  "realRatio": 1
}
```

Как это читать:

* `exponent` и `coeff` задают размер в метрах как `coeff × 10^exponent`
* например:

  * `1 × 10^-7` = 100 нм
  * `1.1 × 10^-7` = 110 нм

---

## 4. Добавить визуальное расположение

В `public/data/visualLocations.json` добавь запись:

```json
{
  "objectID": 329,
  "boundX": 20,
  "boundY": 110,
  "boundW": 380,
  "boundH": 380,
  "titleX": 220,
  "titleY": 470,
  "titleScale": 1,
  "titleWrap": true,
  "descriptionX": 660,
  "descriptionY": 240,
  "zoomOffset": 0.1
}
```

Что важно:

* `boundX/Y/W/H` — область клика
* `titleX/Y` — позиция заголовка
* `descriptionX/Y` — позиция карточки описания
* `zoomOffset` — насколько близко камера подлетает при клике

Проще всего:

* взять объект похожего размера,
* скопировать его `visualLocation`,
* потом подвинуть вручную.

---

## 5. Добавить запись в `items.json`

В `public/img/textures/items.json` добавь блок:

```json
"329": {
  "frame": {
    "x": 0,
    "y": 0,
    "w": 250,
    "h": 250
  },
  "rotated": false,
  "trimmed": true,
  "spriteSourceSize": {
    "x": 1121,
    "y": 716,
    "w": 250,
    "h": 250
  },
  "sourceSize": {
    "w": 2160,
    "h": 1215
  }
}
```

Смысл полей:

* `frame.w/h` — реальный размер PNG
* `spriteSourceSize.x/y/w/h` — положение PNG внутри большого логического холста
* `sourceSize.w/h` — размер логического холста

### Важный принцип

Если хочешь, чтобы объект вел себя как соседний объект того же масштаба:

* возьми у него `sourceSize`,
* подбери `spriteSourceSize.x/y`, чтобы картинка стояла в нужном месте.

---

## 6. Добавить переводы

Во всех locale-файлах добавь ключ нового ID:

```json
"329": {
  "title": "Название",
  "description": "Описание объекта."
}
```

Минимум нужно добавить в `ru`, а лучше сразу во все языки.

---

## 7. Проверить соответствие ID

ID должен совпадать везде:

* `sizes.json`
* `visualLocations.json`
* `items.json`
* locale-файлах
* имени PNG-файла

Например везде `329`.

---

## 8. Проверить загрузку

Если объект не появился, смотри:

* есть ли `329.png`
* есть ли `"329"` в `items.json`
* увеличен ли `MAX_COMMON_TEXTURES`
* есть ли перевод `"329"`

---

## 9. Если картинка смещена

Проверь `items.json`:

* `frame.w/h` должны совпадать с реальным размером PNG
* `spriteSourceSize.w/h` тоже должны совпадать с реальным размером PNG
* `spriteSourceSize.x/y` регулируют положение картинки
* `sourceSize` обычно можно взять от соседнего объекта

---

## 10. Если кликается мимо

Правь в `visualLocations.json`:

```json
"boundX"
"boundY"
"boundW"
"boundH"
```

Потому что hit area задаётся вручную, а не по реальным границам текстуры.

---

## Быстрый практический рецепт

Для нового объекта удобнее всего так:

1. Найти похожий по размеру объект.
2. Скопировать его записи из:

   * `sizes.json`
   * `visualLocations.json`
   * `items.json`
3. Поменять:

   * ID
   * размер (`coeff`, `exponent`)
   * текстуры PNG
   * переводы
4. Подкрутить:

   * `spriteSourceSize.x/y`
   * `boundX/Y/W/H`
   * `titleX/Y`
   * `descriptionX/Y`

---

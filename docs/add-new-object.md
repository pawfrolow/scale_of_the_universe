# Добавление нового объекта на шкалу

## 1. Подготовить PNG

Положи изображение объекта в папку:

```text
public/img/textures/items/NNN.png
```

где `NNN` — новый ID объекта в формате `001`, `248`, `329`.

Рекомендации к PNG:

* прозрачный фон
* без лишних пустых полей, если возможно
* нормальное качество без сильных артефактов
* имя файла должно точно совпадать с ID

Пример:

```text
public/img/textures/items/329.png
```

---

## 2. Добавить ID в список текстур

Если проект всё ещё использует статический список ID в `src/config/index.ts`, увеличь верхнюю границу:

```ts
const MAX_COMMON_TEXTURES = 329
```

Если добавляешь объект `330`, ставь `330`.

Если позже список текстур будет полностью строиться из `items.json`, этот шаг станет не нужен.

---

## 3. Добавить запись в `public/data/items.json`

Теперь вся информация по объекту хранится в одном месте: внутри `frames`.

Нужно добавить новый блок в `frames` по ключу нового ID.

Пример:

```json
"329": {
  "rotated": false,
  "trimmed": true,
  "spriteSourceSize": {
    "x": 1121,
    "y": 716,
    "w": 250,
    "h": 250
  },
  "sourceSize": {
    "w": 2160,
    "h": 1215
  },
  "size": {
    "objectID": 329,
    "exponent": -7,
    "coeff": 1,
    "realRatio": 1
  },
  "visualLocation": {
    "objectID": 329,
    "titleX": 220,
    "titleY": 470,
    "titleScale": 1,
    "titleWrap": true,
    "descriptionX": 660,
    "descriptionY": 240,
    "zoomOffset": 0.1
  }
}
```

---

## 4. Что означают поля в `size`

```json
"size": {
  "objectID": 329,
  "exponent": -7,
  "coeff": 1,
  "realRatio": 1
}
```

Смысл:

* `objectID` — числовой ID объекта
* `exponent` и `coeff` задают размер в метрах как `coeff × 10^exponent`
* `realRatio` — поправка к реальному соотношению размеров

Примеры:

* `1 × 10^-7` = 100 нм
* `1.1 × 10^-7` = 110 нм

Обычно для новых объектов удобно взять `size` от похожего по масштабу объекта и поправить только `coeff` и `exponent`.

---

## 5. Что означают поля в `visualLocation`

```json
"visualLocation": {
  "objectID": 329,
  "titleX": 220,
  "titleY": 470,
  "titleScale": 1,
  "titleWrap": true,
  "descriptionX": 660,
  "descriptionY": 240,
  "zoomOffset": 0.1
}
```

Смысл:

* `titleX`, `titleY` — позиция заголовка под объектом
* `titleScale` — масштаб текста заголовка
* `titleWrap` — перенос строки у заголовка
* `descriptionX`, `descriptionY` — позиция карточки описания
* `zoomOffset` — насколько близко камера подлетает при клике

Удобный способ настройки:

* взять похожий объект
* скопировать его `visualLocation`
* подвинуть вручную после проверки в приложении

---

## 6. Что означают поля TexturePacker-части

Верхняя часть записи отвечает за геометрию текстуры внутри атласа:

```json
"rotated": false,
"trimmed": true,
"spriteSourceSize": {
  "x": 1121,
  "y": 716,
  "w": 250,
  "h": 250
},
"sourceSize": {
  "w": 2160,
  "h": 1215
}
```

Смысл:

* `spriteSourceSize.x/y/w/h` — положение вырезанной части внутри логического холста объекта
* `sourceSize.w/h` — размер исходного логического холста

### Важный принцип

Если хочешь, чтобы новый объект вел себя как соседний объект похожего масштаба:

* возьми у него `sourceSize`
* возьми похожую структуру `spriteSourceSize`
* подстрой `x/y`, чтобы картинка располагалась правильно

---

## 7. Если используется TexturePacker

Если `items.json` генерируется автоматически через TexturePacker, не редактируй его вручную как основной источник.

Тогда процесс такой:

1. TexturePacker генерирует базовый `items.json`
2. post-process скрипт дописывает в каждый `frames[ID]` поля:

   * `size`
   * `visualLocation`

То есть TexturePacker отвечает только за atlas-данные, а проектный скрипт дополняет их доменными данными.

---

## 8. Добавить переводы

Во всех locale-файлах нужно добавить ключ нового ID:

```json
"329": {
  "title": "Название",
  "description": "Описание объекта."
}
```

Минимум — добавить в основной язык, но лучше сразу во все поддерживаемые языки.

ID должен совпадать с ключом в `frames`.

---

## 9. Проверить соответствие ID

Один и тот же ID должен совпадать везде:

* имя PNG-файла
* ключ в `items.json -> frames`
* `size.objectID`
* `visualLocation.objectID`
* ключ в locale-файлах
* при необходимости — в статическом списке `getTextureIds`

Например, если объект `329`, то везде должен быть именно `329` / `329.png`.

---

## 10. Если объект не появился

Проверь по порядку:

* существует ли файл `public/img/textures/items/329.png`
* есть ли ключ `"329"` в `public/data/items.json`
* есть ли внутри него `size`
* есть ли внутри него `visualLocation`
* добавлен ли перевод `"329"`
* увеличен ли `MAX_COMMON_TEXTURES`, если список ID пока статический

---

## 11. Если картинка смещена

Проблему обычно нужно искать в texture-части записи:

* `spriteSourceSize.w/h` должны соответствовать размеру объекта внутри логического холста
* `spriteSourceSize.x/y` регулируют положение изображения
* `sourceSize` можно взять от соседнего похожего объекта

Если новый объект должен вести себя почти так же, как соседний, удобнее всего скопировать у него эти значения и поправить только позицию.

---

## 13. Если заголовок или описание стоят не там

Править нужно:

Для заголовка:

```json
"titleX"
"titleY"
"titleScale"
"titleWrap"
```

Для карточки описания:

```json
"descriptionX"
"descriptionY"
```

Если описание слишком большое или визуально неудачно расположено, проще всего взять координаты у похожего объекта и потом вручную подкрутить.

---

## 14. Если зум при клике слишком слабый или слишком сильный

Правь:

```json
"zoomOffset"
```

Обычно это небольшое число, например:

```json
0
0.05
0.1
```

Чем больше значение, тем ближе камера подлетает к объекту.

---

## Быстрый практический рецепт

Для нового объекта обычно удобнее всего так:

1. Найти похожий по масштабу объект
2. Скопировать его запись из `items.json`
3. Поменять:

   * ID
   * PNG
   * `size.objectID`
   * `visualLocation.objectID`
   * `coeff` / `exponent`
4. Подкрутить:

   * `spriteSourceSize.x/y`
   * `titleX/Y`
   * `descriptionX/Y`
   * `zoomOffset`
5. Добавить переводы

---

## Шаблон чеклиста

* добавить `NNN.png`
* при необходимости увеличить `MAX_COMMON_TEXTURES`
* добавить запись `NNN` в `public/data/items.json`
* заполнить `size`
* заполнить `visualLocation`
* добавить переводы по ключу `NNN`
* проверить появление объекта
* проверить положение картинки
* проверить область клика
* проверить заголовок
* проверить карточку описания
* проверить зум при клике
